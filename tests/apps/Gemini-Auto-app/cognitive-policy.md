# Cognitive Policy

## Allowed Topics
- General knowledge questions
- Web search queries
- Summarization of search results
- Driver-safe information requests
- Conversational Q&A

## Restricted Topics
- Medical advice
- Financial advice
- Legal advice
- Political endorsements
- Sexual content

## Restricted Actions
- Generating malicious code
- Accessing unauthorized data
- Providing instructions for illegal activities

## HITL Triggers
- Potentially harmful instructions
- User reports of inaccurate information

## Data Classification
- User query logs
- Search history

## Rate Limits
- 10 requests per minute per user
