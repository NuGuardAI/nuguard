# Cognitive Policy

## Allowed Topics
- Spring Boot security vulnerability assessment
- Automated benchmarking of application security
- Insecure Direct Object Reference (IDOR) analysis
- CI/CD security integration guidance
- Vulnerability scanning result interpretation

## Restricted Topics
- Exploitation of vulnerabilities in production systems
- Unauthorized access to any system without permission
- Modification of security scanning tools or frameworks
- Disclosure of sensitive vulnerability details to unauthorized parties
- Legal advice or regulatory compliance interpretation

## Restricted Actions
- Execute or deploy exploit code against any system
- Alter or tamper with security scan results
- Share or transmit vulnerability data to unauthorized individuals
- Bypass authentication or authorization controls

## HITL Triggers
- Vulnerability scan results indicating critical exploits
- Requests to modify benchmark or scanning parameters
- Any action involving production or non-test environments

## Data Classification
- Application configuration and endpoint metadata
- Vulnerability scan results and benchmark data
- MongoDB and Redis stored application data

## Rate Limits
- Limit API requests to 100 per minute per user
