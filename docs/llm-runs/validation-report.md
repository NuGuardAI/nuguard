Create and optimize the common reporting for validation runs. This will be used for both Behavior and red-teaming validation runs. 
The report should include:
- A summary of the validation run, including the number of tests conducted, the types of tests, and the overall success rate.
- List of test scenarios and their outcomes, including any failures or issues encountered during the validation process.
- For Red-teaming: A detailed analysis of the Findings, including the severity of each Finding and recommendations for mitigation. For evidence, include the turns (Request and Response) that led to the Finding.
- For Behavior validation: A detailed analysis of the Coverage by AI-SBOM components and Cognitive Policy components. For evidence, include the turns (Request and Response) that led to the coverage results.
- Additionally, both red-team and behavior reports include a details section that includes all the scenarios and the turn details for each scenario, including the request and response for each turn. This section should be organized in a way that allows for easy navigation and reference to specific scenarios and turns.
